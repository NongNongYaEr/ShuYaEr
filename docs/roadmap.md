## 接下来的准备方向

| 方向 | 需要准备的内容 | 当前状态 |
| :--- | :--- | :--- |
| 桌面版发布 | 实际发行文件、适用系统、启动说明、版本变化和已知问题。 | 下载入口待补充 |
| 软件源码公开 | 对应版本的公开目录、依赖、真实构建步骤和运行说明。 | V040 精简源码已公开 |
| 配套植物资产 | 实际素材文件、兼容版本、使用步骤和对应获取入口。 | 随资源准备 |
| 制作演示 | 基于实际软件操作的录屏，说明样板选择、调整、保存与导出。 | 录屏待补充 |
| 授权说明 | 确认后的软件与资产使用规则，以及版本一致的随包说明。 | 本仓库及随包许可已明确 |

以上是准备方向，不表示文件已经上传，也不表示源码或资产已获得某种授权。准备完成后更新状态，再补充实际入口。
