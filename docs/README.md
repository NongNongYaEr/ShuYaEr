## 一次制作的基本路径

| 选择样板 | 调整造型 | 保存工程 | 导出资产 |
| :--- | :--- | :--- | :--- |
| 先建可编辑副本。 | 先轮廓，再局部。 | 保留可继续编辑的文件。 | 为后续制作或交付准备文件。 |

工程、素材包和导出文件各有用途，详见[工程与资产](faq.md#工程与资产)。已有自己的工程时，请先保存备份再继续调整。
