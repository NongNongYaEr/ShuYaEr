## 这与通行的“开源”有什么区别

拟定方案限制修改版的发行和销售，因此应称为“免费使用、源码公开”，不标注为 OSI 开源。标准开源定义要求允许再分发和衍生作品；MIT、Apache、GPL 等许可证不能通过追加一句“禁止售卖修改版”就仍然按原许可证运作。

GitHub 公共仓库的查看和平台内 Fork 仍按 GitHub 服务条款处理。不能把平台允许的 Fork 本身一概视为违规，也不能把 Fork 当作获得站外发行或销售授权的证明。

## 关于拟议的责任金额

软件修改版违规发行／销售拟议违约金为 **100 万元**，素材违规转售拟议违约金为 **10 万元**。这些金额尚待审阅，**不是平台有权开出的罚款，不是自动生效或保证法院支持的最低赔偿额**。有效合同、条款提示、损失及具体事实均会影响认定；依法可以请求调整违约金。

侵权责任与合同责任分别依法判断，不能靠一段 README 让全部访客自动承担高额违约金。
