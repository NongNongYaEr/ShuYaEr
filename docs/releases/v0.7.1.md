# 树鸭儿 V071 / 0.7.1 · 精简公开源码

- 树干「一键准备」接入新版自动 UV，沿树干、根盘和细枝合并碎岛。UV 精修可比较覆盖率、拉伸与岛距。
- 带贴图的树干 GLB 可以保留原材质，再叠加积雪、苔藓等效果。
- 叶花果支持拖挂、复制、框选、按区批量生成与梳理，可随整树导出到 UE/PVE。
- 支持导入完整静态花盆 GLB。预览可缩小大贴图，导出时保留原始贴图。
- 图形设置支持自动、DX12 和兼容模式。
- 对应的单文件 EXE 默认在旁边的「树鸭儿数据」解包并缓存，必要时使用同盘备用目录。

精简源码附带 8 类整株样板、43 款可浏览单元枝、8 套叶花果和 1 个预制枝干。

已验证对应精简 EXE 与全资产 EXE 从 D 盘空缓存启动、两套工作台的 DX12 渲染，以及使用同版精简 EXE 在干净目录还原 670 个样本文件并重建桌面程序。

已有对应 V071 精简 EXE 的用户，可按[构建指南](../build-source.md)还原运行依赖。此 GitHub 版本提供精简源码和样本。
