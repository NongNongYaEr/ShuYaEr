# 树鸭儿 V040 / 0.4.0

2026-10-30。Windows x64 精简公开源码，主视口 DX12，工程格式 4、视口 ABI 1。继承 [V0.3](v0.3.0.md) 的树干整理、完整单元枝装配、笔刷和带骨骼 GLB。

## 模型雕刻与编辑改进

- **轻量模型雕刻**：为导入的 GLB 调整局部造型，提供抓取、拉伸、弯曲、收尖、鼓起／压入、收拢／扩张、平滑、压平／填平、局部还原和保护遮罩。原网格拓扑、UV 与材质保留，大幅拉伸可能带来贴图拉伸。
- **笔刷操作**：F 调半径，Shift+F 调强度，Shift 临时平滑、Alt 反向；可在笔刷覆盖网格时从空白处开始拖动。支持范围选取、隔离、G/R/S 变换与逐笔撤销。
- **树干控制点**：改进直接点选／拖框多选及局部缩放范围，避免编辑个别枝干时错误影响其他枝干。
- **完整单元枝梳理**：修复工具切换与挂接根部漂移；木枝、叶花果和材质随整支实例转向，内部造型继续在枝条工作台制作。
- **视口与装配反馈**：空白处取消选择后隐藏控制点和线，选中对应对象时再显示；改进目标数量容量的计算与提示。

## 软件内风动模拟

从主视窗的“风动预览”或“预览 → 风动模拟”进入，调整风向、强度和预设，支持播放、暂停、单步和速度控制。根部固定，承重结构弯曲，完整单元枝按整体跟随。

风动用于大致观察，不要求与 UE/PVE 完全一致。停止、退出或保存时恢复实际编辑造型；工程可保存风动参数，重新打开不会自动播放。本版不把临时风动姿态烘焙进模型，也不导出风动动画。

## 样本与运行

附带 8 个整株样板、43 款可浏览单元枝、8 套叶花果和 1 个预制枝干，覆盖乔木、灌木、观叶、常春藤、花藤、草叶、大叶草本和花卉；必要的内嵌单元枝依赖同时保留。见[资产清单](../../资产清单.json)。

样本复用已公开的压缩分卷，按块及最终文件 SHA256 还原。完整资产库、个人工程、恢复草稿、EXE、DLL 和开发缓存不包含在本次源码提交中。

使用与本版对应的 0.4.0 精简单文件 EXE 按[构建指南](../build-source.md)准备运行依赖。EXE 由作者单独提供；公开下载链接待补充。不要混用 0.3.x 的运行包。

## 验证范围

V0.4 归档已通过 79 项开发回归、30 项精简核心检查、八类样本逐项 DX12 重开、单 EXE 首次／再次启动与 947 个内置文件校验、公开源码独立重建、真实雕刻树恢复工程重开，以及 8 项真实 DX12 风动检查。

骨骼 GLB 导出模块与此前 Blender 验收版本逐字节一致，保留此前证据；本轮不另做 UE 风动对照。自动骨架仍是可检查、可手动修正的辅助结果。
