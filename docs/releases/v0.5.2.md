# 树鸭儿 V052 / 0.5.2 · 树干材质与骨架验收

- 树干整理在同一窗口串起模型准备、材质制作、检查保存和自动骨架绑定。
- 骨架点选和框选支持穿透网格，删除确认显示在鼠标旁，骨架编辑视口的闪烁已修复。
- 权重修复可扫描拉伸异常、自动修复并反馈处理结果，也可用笔刷局部修整。
- 弯曲验收支持选中骨骼试转、按轴约束和聚焦。属性栏底部可返回骨架编辑，重进时恢复静止姿态。

精简源码附带八类样本。植物工程格式为 4，材质工程格式为 25，DX12 ABI 为 1。已有对应 V052 精简单文件 EXE 时，可按[构建指南](../build-source.md)还原依赖。

发布验收覆盖 51 项自动测试、公开源码重建、双 DX12 视口、骨架返回操作和精简版 2K GLB 导出。
