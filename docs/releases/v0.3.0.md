# 树鸭儿 V030 / 0.3.0

2026-10-29。Windows x64 精简公开源码，主视口使用 DX12，工程格式 4、视口 ABI 1。

## 这一轮更新

- **外部树干整理**：导入雕刻或 AI 树干 GLB，校准底点、方向与真实尺寸，布置控制骨架；自动识别提供可检查、可手动修正的候选骨架。
- **树干与枝干编辑**：控制点多选、移动、旋转、缩放和弯曲；控制线挂接完整单元枝，保留外部模型的网格、UV 与材质。
- **完整单元枝笔刷**：刷生成、按住 Alt 擦除，以及整体大小、加密／稀疏操作。木枝、叶花果和材质始终按完整单元枝实例一起处理，内部细节在枝条工作台制作。
- **GLB 输出**：可选静态网格或骨骼绑定。绑定版保存当前造型的绑定姿态与贴图；完整单元枝内部保持整体，默认不附带动画。

## 公开样本

覆盖乔木、灌木、观叶、常春藤、花藤、草叶、大叶草本和花卉：8 个整树样板、43 款可浏览单元枝、8 套叶花果、1 个预制枝干，以及依赖中完整内嵌的必需单元枝。具体内容见[资产清单](../../资产清单.json)。

样本通过清单还原，复用仓库原有压缩分卷，逐块及逐文件校验 SHA256。完整资产库、用户工程、恢复草稿、EXE 与 DLL 不包含在本源码提交中。

## 构建与验证

按[构建指南](../build-source.md)使用与本版对应的精简单文件 EXE 准备依赖，再编译桌面壳。EXE 由作者单独提供，公开下载链接待补充。

V0.3 归档已完成核心检查、八类样本 DX12 冷启动、真实工程保存重开和单文件资源校验。带骨骼 GLB 已在 Blender 5.0.1 完成导入、摆动、保存和重开检查。本轮 GLB 验收使用 Blender；未追加 UE 验收。

自动骨架是辅助结果；分叉、树洞、相邻枝干和细枝仍应在应用前检查，并在需要时手动修正。
