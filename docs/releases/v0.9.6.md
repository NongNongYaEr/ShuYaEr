# 树鸭儿 V096 / 0.9.6 · 精简公开源码

- 「叶花果 → 整包 GLB 拆分整理」可选合并枝皮和叶花果材质。共用同一张不透明颜色图集的枝皮与叶花果可共用材质，几何仍可分别编辑。
- 树干「保留模型，只制作材质」会提示是否接受原 UV 的少量重叠。接受后可保留原 UV 继续制作。需要重展时可选「高模完整处理」。
- 灯带沿弯干平缓转向，尝试绕过根槽和分叉补接断口，并检查穿皮和相邻圈的距离。已有灯带可在「灯带 → 立即更新」重新生成。
- 配套 UE 工作台 0.2.72 在生成网格时复用同源同色的枝叶材质。用实际榕树工程验证了主干、灯带和共享枝叶图集三个有效材质槽。

精简源码附带八类代表样本、43 款单元枝、9 套叶花果和 1 个预制枝干。

已在干净目录用同版精简 EXE 还原运行依赖和 680 个样本文件并重建，通过植物与材质工作台的 DX12 启动检查。取得「树鸭儿V096.exe」后，可按[构建指南](../build-source.md)准备运行依赖。

本次 GitHub 发布提供源码和样本。单文件 EXE 和配套 UE 工作台随桌面交付。
