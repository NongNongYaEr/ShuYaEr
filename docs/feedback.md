**提交前先找一找：** [常见问题](faq.md) · [已有讨论](https://github.com/NongNongYaEr/ShuYaEr/issues)。如果已有相同问题，可以在原讨论补充自己的复现信息。

GitHub Issues 用于公开的软件问题与功能讨论，需要登录 GitHub 才能提交。账号、订单、付款和会员问题，通过软件所属网站的站内反馈处理；正式站点入口公布后补充。

## 反馈一个软件问题

请尽量提供：

1. 软件版本；文档问题填写页面名称。
2. 操作系统和发生问题的工作区。
3. 从什么状态开始，按什么步骤操作后出现问题。
4. 实际表现与期望结果。
5. 如有帮助，可附截图、最小示例或相关报错文字。

公开 Issue 中不要填写账号密码、订单信息或未公开项目资料。日志与截图先移除个人和项目敏感信息，复现素材优先使用可以公开的最小示例。

## 提一个功能建议

说明你在制作什么、哪一步遇到阻碍，以及希望怎样改善。可补充现有替代做法和具体例子，帮助判断需求适合解决哪类任务。

一个 Issue 尽量聚焦一个问题或建议。提交后如有新的复现结果，可继续补充到原讨论。

## 提交之后

保留 Issue 地址，后续的补充、讨论和处理进展都放在同一条记录中。有了新的复现步骤或确认问题已经解决时，也可以继续补充。

如果想直接修改文档、修复链接或补充使用说明，可以先看[参与改进指南](../CONTRIBUTING.md)，再提交聚焦一个问题的 PR。

源码和发行包仍在整理，可先查看[当前准备进度](source-status.md)。
