# 反馈与建议

GitHub Issues 用于公开的软件问题与功能讨论。账号、订单、付款和会员问题，通过软件所属网站的站内反馈处理。

| 内容 | 入口 |
| --- | --- |
| 启动失败、制作异常、工程或导出问题、文档错误 | [软件故障反馈](https://github.com/NongNongYaEr/tree-duck/issues/new?template=bug_report.yml) |
| 制作需求、效率改进和功能想法 | [功能建议](https://github.com/NongNongYaEr/tree-duck/issues/new?template=feature_request.yml) |
| 账号、订单、付款和会员权益 | 软件所属网站中的站内反馈；正式站点入口公布后补充 |

## 反馈一个软件问题

先查看 [已有 Issues](https://github.com/NongNongYaEr/tree-duck/issues)，有相同问题时可在原讨论补充复现信息。

请尽量提供：

1. 软件版本；文档问题填写页面名称。
2. 操作系统和发生问题的工作区。
3. 从什么状态开始，按什么步骤操作后出现问题。
4. 实际表现与期望结果。
5. 如有帮助，可附截图、最小示例或相关报错文字。

公开 Issue 中不要填写账号密码、订单信息或未公开项目资料。日志与截图先移除个人和项目敏感信息，复现素材优先使用可以公开的最小示例。

## 提一个功能建议

说明你在制作什么、哪一步遇到阻碍，以及希望怎样改善。可补充现有替代做法和具体例子，帮助判断需求适合解决哪类任务。

一个 Issue 尽量聚焦一个问题或建议。提交后如有新的复现结果，可继续补充到原讨论。

源码和发行包仍在整理，可先查看 [当前准备进度](source-status.md)。
