# 常见问题

## 现在能从这个仓库下载软件吗

当前仓库提供介绍、使用文档、界面预览和反馈入口，尚未提供安装包或可构建的软件源码。正式下载入口准备好后，会在项目首页公布。

## 桌面版和源码应该选哪个

想直接开始制作，选择正式发布的桌面版。想研究、自行构建或参与开发，等待对应版本源码与构建说明公开后获取源码。

GitHub 仓库 ZIP 包含该版本实际提交的内容；目前下载它只能获得文档和图片，不能代替桌面版或完整源码。

## V0.1 精简试用版需要安装吗

这个版本的 ZIP 内包含 `树鸭儿.exe`，解压后双击使用，没有安装向导；运行需要 Windows x64 和系统 WebView2 Runtime。其他版本按各自随包说明操作。

## 工程和植物素材包有什么区别

`.branch.json` 是用于继续编辑的工程文件。其他素材包按该资产的格式、兼容版本和使用步骤打开，不能把所有包都当作工程。

保留来源素材原件，创建可编辑副本，再把自己的修改另存为工程或新样板。

## 保存工程和导出资产有什么区别

保存工程用于继续编辑；导出资产用于交付或后续制作。建议先保存工程，再导出，并分别保留两类文件。导出格式与选项以当前版本的面板为准。

## 怎么备份或迁移已有作品

先手动保存正式工程，保留素材和随包说明要求的运行文件。V0.1 单文件版的本地库、草稿与运行资源还涉及当前用户的本地应用数据目录，迁移时应一并备份。

这个版本没有跨电脑、跨版本的自动迁移流程。迁移前先备份，在目标环境确认工程能正常打开后，再继续制作。

## 源码公开后，配套植物资产也会一起提供吗

软件源码与配套资产分别维护。素材获取范围、版本兼容与授权，按网站资产库中对应内容的说明执行。目前已整理免费使用、修改版发行限制和素材商用的 [授权草案](licensing.md)，尚未生效。

已确认的到期政策是：有效会员期间合法领取的素材版本，正常到期后仍可用于新旧商业项目；到期停止按该权益继续领取，不自动包含未来更新或重新发放链接。使用前仍须核对最终公布的适用协议。

## 应该在哪里反馈问题

启动、制作、保存、导出或文档问题，可提交 [软件故障反馈](https://github.com/NongNongYaEr/tree-duck/issues/new?template=bug_report.yml)。制作流程或功能方面的想法，可提交 [功能建议](https://github.com/NongNongYaEr/tree-duck/issues/new?template=feature_request.yml)。

账号、订单、付款和会员问题，通过软件所属网站的站内反馈处理；不要在公开 Issue 中填写订单或账号资料。详见 [反馈指南](feedback.md)。
