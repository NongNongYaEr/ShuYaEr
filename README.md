## 把自然，做进你的世界

树鸭儿面向游戏场景、植物制作与环境美术。从完整样板建立植物轮廓，再进入枝条与藤蔓工作区处理细节，让制作过程保留继续调整的空间。

| 制作任务 | 在树鸭儿里做什么 |
| --- | --- |
| **整树造型** | 从整株植物样板出发，调整轮廓与枝叶组合。 |
| **枝条编辑** | 细化植物结构，组合样本并调整局部形态。 |
| **藤蔓制作** | 为模型组织植物的覆盖与垂挂，丰富建筑和道具层次。 |

## 桌面版、源码与配套资产

**桌面版**适合直接开始制作，由弄弄鸭儿大公司网站提供下载；正式入口确认后会在这里公布。当前仓库尚未提供安装包。

**源码**用于研究、自行构建和参与开发。软件源码仍在整理，后续将与对应版本的依赖、构建步骤和授权说明一起公开。当前仓库里的文档与图片不是完整软件源码。

**配套资产**在网站资产库单独提供。植物样板、枝条和藤蔓素材的可获取范围与授权，按各自内容说明维护。

源码标签与桌面版版本会分别标注，获取时请核对；实际发行记录以 [Releases](https://github.com/NongNongYaEr/tree-duck/releases) 中已发布的内容为准。
