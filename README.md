# 树鸭儿 · TreeDuck

面向游戏场景与 3D 创作的植物工具，由 **弄弄鸭儿大公司** 开发。

## 功能方向

- **整株造型**：从完整植物样板出发，调整轮廓与枝叶层次。
- **枝条编辑**：细化植物结构，组合和调整枝条。
- **藤蔓制作**：沿模型组织植物的覆盖与垂挂。

## 项目状态

项目正在初始化。本仓库先提供项目介绍；软件源码、构建步骤和版本说明仍在整理，尚未发布。

桌面版版本和源码标签会分别标注，获取时请核对。当前没有提供可构建的软件源码或安装包。
