## V0.3 · 从外部树干到完整植物

本轮更新了雕刻／AI 树干整理、控制骨架与完整单元枝装配，并补齐刷生成、Alt 擦除、大小与密度笔刷。导出可选择静态 GLB 或带骨骼绑定的 GLB；带骨骼版本保留当前造型和材质，供 Blender 等软件继续制作。

精简源码附带八类可用样本，覆盖树、灌木、常春藤、花藤及草本。[查看 V0.3 更新说明 →](docs/releases/v0.3.0.md)

## 下载与资源，分清这三件事

| 桌面版 | 软件源码 | 配套资产 |
| :--- | :--- | :--- |
| 用于直接开始制作。正式下载入口确认后公布；本仓库目前没有提供安装包。 | V030 精简源码、依赖准备脚本及构建说明已公开；从[构建指南](docs/build-source.md)开始。 | 源码附带八类代表样本和完整依赖，完整素材库单独提供；见[素材许可](ASSETS_LICENSE.md)。 |

桌面版、源码标签与资产分别标注版本；实际可获取文件以对应项目说明和[发行记录](https://github.com/NongNongYaEr/ShuYaEr/releases)为准。正式官网地址准备好后会补充到这里。
