# 树鸭儿 {{VERSION}} · {{VARIANT}}

这是 V020 确定版本的 Windows x64 独立运行目录。双击 **树鸭儿.exe**，保留整个目录中的依赖文件；无需本机安装 Node.js 或开发工具。系统需要 WebView2 以及支持 DirectX 12 的显卡。

精简版按植物用途保留代表样本：香樟、杜鹃、琴叶榕、常春藤、三角梅、草叶、大叶草本和黄色小花。每个样本保留实际使用的完整单元枝、叶花果与贴图依赖，不通过删除依赖制造体积缩小。完整版保留当前完整素材库及已保存样板、预制枝干。实际数量见 `资产清单.json`。

资源中心可浏览素材，导入／导出 `.plantpack` 资源包；叶花果整理台用于整包 GLB 拆分和校准。「整包总览」位于整理台左侧单元列表顶部。

首次运行在本目录建立 `.runtime` 缓存、配置和恢复草稿；不会读取原开发目录的编辑记录。工程格式 4、视口 ABI 1、UE/PVE 约定保持。请主动另存重要工程。
